# EdgeSlicer 2.4.3.0

<!-- update-notice -->
New in 2.4.3.0:
- Home: Models browser in the Home tab (Windows beta).
- Bambu High Flow for the H2D, H2C, H2S and P2S, along with High Flow filament/slicing fixes for the U1 and others.
- Add Custom Models, for quick import similar to Handy Models.
- Dark mode for the Snapmaker U1 pages.
- Move tool: alignment origins and an anchor.
- Supports: side stabilizers, with Bake-in.
- Strength: SLA-style hollowing.
- Right-click: Edit in FreeCAD.
- Phone app: Live Activities, printer timelapses, per-event notification levels, cameras that stop streaming when off-screen, and fixed filament/device displays for some printers.

Fixes:
- Align selected can lift objects onto others.
- The upstream Snapmaker memory warning can now be turned off.
- Device tab fixes for the FlashForge Creator 5.
- Safer file handling: downloads never overwrite files, and saves are atomic.
- Bambu by-object clearances adjusted, and timelapse visuals fixed.
- Both H2 chamber lights are now controlled together.
<!-- /update-notice -->

Everything in [2.4.2.0](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.2.0-edge) is included.

## New

- **Models browser** (#281, Windows, beta). Home › **Models** opens Printables, MakerWorld and Snapmaker Space inside EdgeSlicer, with back/forward/reload, an address bar and an Open in browser button. Logins are kept, but the browser is isolated from the rest of the app: it shares no cookies or storage with it, cannot talk to it, and cannot open local or private-network addresses. Model files you download (.3mf, .stl, .step, .stp, .obj, .zip) open straight in the slicer; programs and scripts are refused, and files from unknown sites ask first. Turn it off in Preferences › General › **Model browser (beta)**.
- **Bambu High Flow** (#280). The H2D, H2D Pro, H2C, H2S and P2S now offer Standard and High Flow columns for filaments, processes and printers, worked out from Bambu's own variant names. No profile changes were needed.
  - On the H2D and H2C, the nozzle type of each side (Standard / High Flow) is followed per filament, and a filament mapped to High Flow without a High Flow column falls back to its Standard values with a notice.
  - The nozzles you have fitted are picked up from the printer when you re-slice.
  - Process speeds and accelerations for a High Flow filament come from Bambu's High Flow slot.
  - Export Bambu 3MF writes the right column for each filament.
  - The X2D, X1, X1C, X1E, P1P, P1S, A1, A1 mini and A2L stay Standard-only.
  - Pressure advance follows the filament's flow variant at every toolchange (#258, adapted from OrcaSlicer #15986). The Filament tab's toggles and temperature ranges follow the Standard / High Flow view (#270, adapted from OrcaSlicer #16007), and the Snapmaker U1 end G-code now reports each filament's `standard` / `high_flow` type (#169, from OrcaSlicer #15755).
- **Custom Models** (#283). **Add Custom Models** sits next to Add Primitive and Add Handy Models in the right-click menus, and lists the .stl, .obj, .step, .stp and .3mf files in your `custom_models` folder (sub-folders become sub-menus; the folder is re-read each time). **Save to Custom Models...** on an object stores its parts, modifiers, per-object settings, painting and filament, but no presets or plate position. A model you add lands on a free spot and is one undo step; settings that aren't safe to import are dropped with a notice.
- **Alignment origins and anchor** (#274). The Move gizmo's Align row has an origin dropdown per axis (X: Auto/Center/Left/Right, Y: Auto/Center/Front/Back, Z: Auto/Center/Bottom/Top), so any point of the selection can go to any point of the plate or of another object. For Align selected, an **Anchor** dropdown (Last selected, First selected, a named item, or the selection bounds) says which object stays put. Auto is the old behaviour. Choices are remembered. Each align is now one undo step.
- **Side stabilizers and hollowing** (#226, #238, #263, #239).
  - **Side stabilizers** (Support tab, per object) brace tall, slender parts such as spires and staffs: pillars stand on the bed and 45° struts end in a pinpoint tip on the part's side wall. They print as support and snap off.
  - **Off / Auto / Manual.** Auto picks the points. You can also paint stabilizer points in the support painting gizmo (**Paint stabilizer points**); Manual uses only your painted points.
  - **Shape and strength options:** tapered pillars, bracing between pillars (with a maximum bracing span), rounded-rectangle columns, and walls with sparse infill inside the stabilizer bodies.
  - **Bake stabilizers** turns the generated stabilizers into a separate object, so other slicers receiving the 3MF can print them too.
  - **Hollow interior** (Strength tab, per object or part) prints an even-thickness shell around an empty cavity, with a warning and a suggested shell thickness when it cannot fit. There are no drain holes yet.
  - **Bake slice to mesh... > Add as new** now lands on the plate of the source object instead of plate 1 (#239).
- **Edit in FreeCAD** (#230). Right-click a part › **Edit in FreeCAD**; saving in FreeCAD (or **Update EdgeSlicer**) replaces the part in place, keeping its placement, name and settings, as one undo step. Parts with an exact CAD shape round-trip as STEP and stay exact. From FreeCAD, **Send to EdgeSlicer** adds bodies to the open window. Install the add-on from Preferences › FreeCAD › **Install FreeCAD add-on**.
- **Snapmaker U1 pages in dark mode** (#256, #266). The U1 Device tab and the pre-print / pre-send pages now follow dark mode and theme packs, using the same colours as the Bambu Device page, and switch live.
- **Cameras stop when you are not looking** (#271). On the hub's camera wall and stand-alone player, tiles that are off-screen or on a hidden page stop streaming and start again when visible. This frees printer camera slots, the hub's transcoder, battery and data. The slicer's own Stream tab does the same when it is hidden or the window is minimised.
- **Bambu first-time setup notice** (#257). A short checklist of what a Bambu printer needs to show up: account, Windows Firewall, LAN Only / Developer mode, access code and microSD card, with live status for the account and firewall.
- **Check Windows Firewall** (#244, Windows). Help › **Check Windows Firewall...** finds why Bambu printers don't appear (missing rules on a portable copy, a Block rule, a Public network) and fixes it with one UAC prompt. Also reachable from Open Network Test and from "Can't find my devices?".
- **Account button highlight** (#259). The Account button turns yellow when the selected printer's account (Bambu Lab or Snapmaker) is signed out, with the reason on hover and a "signed out" line in the menu.
- **Raise3D N2 and N2 Plus** printer profiles (#264) and seven Raise3D-branded filament presets for the N2, N2 Plus, Pro3 and Pro3 Plus (#265).
- **Remember the last print action** (#223, adapted from OrcaSlicer #15774). Preferences option (off by default) to restore the print button's dropdown choice next session.
- **Log level** (#242). Preferences › Extras › Troubleshooting has a Log level dropdown (fatal to trace) that applies immediately, for support logs.

## Behaviour changes

- **Per-filament flow ratio on the H2D, H2C, H2S and P2S.** With the new Standard / High Flow columns, each filament now extrudes with its own flow ratio, as in Bambu Studio, instead of filament 1's. Single-filament prints, and prints where every filament has the same ratio, are unchanged. Multi-filament prints with different ratios will change.
- **No Standard/Custom flow popup on dual-nozzle Bambu printers.** The flow-grouping dialog no longer appears, because the flow type now follows the filament-to-nozzle map. The AMS filament mapping is unchanged.
- **Align selected can lift objects.** Alignment no longer drops objects back onto the bed afterwards, so Align top or bottom between objects of different heights, and the new Z origins, really leave one object on top of another. Parts keep their old behaviour.
- **The memory warning can be turned off** (#284). The slicing "Memory Usage Warning" has a "Don't ask again" box (kept only if you choose Yes, Continue), and Preferences › General › **Warn when memory is low during slicing**. With it off, slicing continues without the toolpath preview and you get a notification and a log line instead. The hub and headless runs still stop, because nobody can answer.
- **Downloaded 3MFs always show the modified G-code warning** (#281). Files downloaded from the web this session (the Models browser, Open in links, MakerWorld) get the modified/custom G-code warning even if you ticked "Don't show again" for local files.
- **Bambu by-object clearance** (#241). The by-object extruder clearance now uses Bambu Studio's `extruder_clearance_max_radius` on Bambu printers: H2D/H2C 96 mm (was 49), H2S 81 (was 30), X1/P1 68 (was 57). By-object plates on these printers may need more space between objects.
- **Phone hub handover** (#285). A newly started EdgeSlicer asks a hub that belongs to a different install to quit (waits up to 10 s, never kills it) and starts its own, and a hub whose install folder has gone quits by itself.

## Phone app and hub

- **Printer timelapses** (#245). The hub lists, thumbnails and streams a printer's timelapse videos to the phone (with seeking), for Moonraker printers and, over the LAN with an SD card, Bambu printers.
- **Notification levels** (#272). The hub accepts the app's per-device levels: kinds the phone treats as urgent are sent at high priority, a phone with its own levels gets every event and decides itself, and failed pushes are dropped after 4 hours. Apps that don't send levels behave as before.
- **The hub no longer advertises addresses the phone can't reach** (#282): WSL, Hyper-V, Docker and VPN adapters, and raw Tailscale IPs over https. Only up Wi-Fi and Ethernet adapters are listed, the default-route address first. The phone no longer tries bad addresses before it connects.
- **Both chamber lights on the H2D, H2C and H2S** switch together (#246).
- **A clear 503 page and a log line when the hub's web pages are missing** (#279), instead of black camera tiles.
- Camera tiles pause off-screen (see New) and the Stream tab pauses with them.

## Fixes

- **Bambu H2D/H2C timelapse** (#240). The timelapse position picker from Bambu Studio is ported, so the head moves to the farthest safe point for each photo instead of staying put or parking on every layer.
- **FlashForge:** FlashNetwork now starts, which fixes the Creator 5 camera page and the FlashForge tab (#243). The missing `FLASHNETWORK9.DAT` now ships next to `FlashNetwork.dll`.
- **Slicing and G-code:**
  - A false wipe tower conflict with "no sparse layers" is gone (#237).
  - Adaptive pressure advance is applied in G-code order at toolchanges, so the output no longer varies between slices (#235).
  - Neighbour-layer data races in extra bridge layers and lightning anchors are fixed (#236).
  - Concentric ironing no longer loops forever with a zero spacing (#249, from OrcaSlicer #15949).
  - Gyroid infill is generated over the region only, which is faster (#221, OrcaSlicer #16002).
  - Re-exporting an already-sliced plate gives the same G-code as the first export (#253, OrcaSlicer #16025).
- **Calibration:** Flow rate no longer starts in spiral mode after a spiral calibration, and its tiles are arranged with clearance (#278). "nan" no longer shows in the High Flow Setting Overrides, and the flow type of the right nozzle is used on mixed H2D/H2C (#270).
- **Mesh Boolean:** the result part no longer jumps after Union, Difference or Intersection (#273).
- **Painting:** Color Mixing Match no longer gets overwritten by the next stroke when the colour painting gizmo is open (#248, Snapmaker #954).
- **Bambu Studio preset mirror:** only copies that landed are recorded, files are replaced safely and matching copies are adopted, so presets no longer stop updating after a failed copy (#275).
- **Edit in Blender** no longer sends the part back, clearing its painting, on the session's first save (#229).
- **Dragging objects in by-object print** no longer risks a crash from an unstable sort (#251, OrcaSlicer #16029).
- **OBJ import:** textured quads get the right UVs (#269, OrcaSlicer #15977).
- **Command line:** crashes on an empty or negative assemble-list `filaments`, `--assemble` without input and `--arrange` without plate data are fixed (#276, OrcaSlicer #15978), and the remaining empty printable height reads are guarded (#219, OrcaSlicer #16016).

## Under the hood and safety

- **Safe downloads** (#234, OrcaSlicer #15955). Downloaded file names are sanitized first, then a free name is picked, so a MakerWorld, Printables or Open in download never overwrites a file or leaves the download folder.
- **Atomic saves** (#255, OrcaSlicer #15861). Settings, presets and the preset cache are written to a temporary file and renamed into place, so a crash or full disk can't leave a torn file. If the replace is refused (an indexer or OneDrive holding the file), the file is written in place with a warning.
- **Per-save lock** (#268, OrcaSlicer #15861). Each save of the config or a preset holds a short file lock, so two EdgeSlicer windows or the hub don't interleave. A save that can't get the lock within 1 s goes ahead anyway: no write is refused.
- **Safer archives and files:** profile update and plug-in archives are confined to their folder and rejected whole on any bad entry (#227, OrcaSlicer #15957); oversized 3MF XML entries are rejected (#225, OrcaSlicer #15958); malformed JSON from print hosts and the cloud no longer throws out of callbacks (#220, OrcaSlicer #15947); project pages show https-only images and open attachments only from the project's own folder (#250, OrcaSlicer #15956).
- **Faster:** opaque objects draw front to back (#254, OrcaSlicer #15884), static print configs apply by type (#252, OrcaSlicer #15658 and #16026), and preset JSON loading avoids locale lock contention (#222, OrcaSlicer #15943).
- **Build and tests:** Debug configs no longer get a Release mapping (#247, OrcaSlicer #14593), the assemble-list parser moved into libslic3r with tests (#277), and a watchdog and determinism test cover the no-sparse wipe tower hang (#233).

## Companion app

Everything below is in the app builds that go with this release (EdgeSlicerApp #16 and #21).

- **Printer timelapses** (Android and iOS). A Timelapses button on the printer screen lists videos with thumbnails, plays them in the app, and shares or saves them (#16).
- **Notification levels.** Quiet, normal or urgent per event kind, decided on the phone: started and resumed are quiet, finished, paused and cancelled are normal, run-out, failed and error are urgent (time-sensitive on iOS, heads-up on Android) (#19, via #21).
- **Live Activity** on iOS (lock screen, Dynamic Island, Apple Watch, CarPlay) and a progress notification on Android 16 (#17, via #21).
- **Cameras pause** when off-screen, on another tab or in the background, and restart when shown (#21).
- **Timelapse download** is safe for async code on iOS (#20, via #21).
