# 将可变层高相关的几何网格算法封装为 snapmaker-geom 纯几何接口

## 目标与定位

把 OrcaSlicer `SlicingAdaptive` 里**纯粹的几何网格算法**抽取到独立库 `D:\00Code\SnapmakerSpace\snapmaker-geom`，封装为：
- `snapmaker_geom::mesh` 命名空间下的**自由函数 + POD 结构**（算法层）
- `GeomAPI` 静态门面方法（返回 `ErrorCode`，结果走 out-param，`guard` 模板）——**门面层文档注释要详尽**
- GoogleTest 单元测试

**两个模块全部实现真实算法（无桩）**：
1. **斜率（slope）** —— 移植自 OrcaSlicer，面斜率数据、cusp 高度、层高推进、水平面距离。
2. **曲率（curvature）** —— 净新增，实现 Meyer 2002 / Taubin 1995 / Rusinkiewicz 2004 三种离散曲率估计算法，配球体/圆柱/平面等已知曲率几何体的单元测试。

**完全独立于 OrcaSlicer**：不含 `ModelObject`/`SlicingParameters`/`quality_factor`；几何层只接受 `indexed_triangle_set` 与数值参数。

**不修改 OrcaSlicer 任何代码**。

### 2. `src/algorithm/include/snapmaker_geom/algorithm/mesh/curvature.h`（实现）

#ifndef snapmaker_geom_mesh_curvature_h_

### 4. `src/algorithm/src/curvature.cpp`（**核心：三种真实算法**）

共用辅助：内部先用 `compute_vertex_normals(its, AngleWeighted)` 得顶点法向 `vn[]`。

#### 4.1 Meyer（默认）—— 离散微分算子

两遍扫描，**无需显式邻接结构**（逐面累积到顶点数组）：

**Pass 1（逐面累积）**，对每个面顶点 `(pa,pb,pc)`，下标 `(ia,ib,ic)`：
```
ab=pb-pa, ac=pc-pa
cross_n = |ab×ac|;  dot = ab·ac
cotA = dot/cross_n        // 角A(在pa)的余切
area = cross_n/2
angleA = atan2(cross_n, dot)
// 同理算 cotB/cotB/angleB、cotC/angleC
```
- **平均曲率法向累积**（离散 Laplace-Beltrami）：
  ```
  K_acc[ib] += cotA*(pb-pc);  K_acc[ic] += cotA*(pc-pb)   // 边(b,c)对边顶点a
  K_acc[ia] += cotB*(pa-pc);  K_acc[ic] += cotB*(pc-pa)   // 边(a,c)
  K_acc[ia] += cotC*(pa-pb);  K_acc[ib] += cotC*(pb-pa)   // 边(a,b)
  ```
- **Gauss 角度亏损**：`angle_sum[ia]+=angleA` 等
- **Voronoi 面积**：
  - 钝角三角形：钝角顶点 += area/2，其余 += area/4
  - 非钝角：`area_acc[ia] += (|ab|²·cotC + |ac|²·cotB)/8` 等

**Pass 2（逐顶点定稿）**：
```
A = max(area_acc[vi], 1e-12)
Kc = K_acc[vi] / (2*A)                      // 平均曲率法向
H_mag = Kc.norm()/2
H = (Kc·vn[vi] < 0) ? +H_mag : -H_mag       // 凸(法向反向)→正
Kg = (2π - angle_sum[vi]) / A
disc = sqrt(max(H²-Kg, 0))
k1=H+disc, k2=H-disc
out[vi] = {max(k1,k2), min(k1,k2), H, Kg}
```

#### 4.2 Taubin —— 切平面二阶基本形式最小二乘

对每个顶点 `vi`，法向 `n=vn[vi]`：
1. 建切平面正交基 `t1,t2`（`t1 = 任意⊥n 的单位向量；t2 = n×t1`）
2. 收集 1-ring 邻接边（遍历所有面，记录含 `vi` 的面的另外两个顶点 → 去重得邻接顶点集）
3. 对每条边 `(vi,vj)`：
   ```
   e = vj-vi;  L=|e|
   k_n = 2*(n·(vi-vj))/(L*L)         // 方向法曲率（凸>0）
   d = e - (e·n)n;  t = normalize(d)  // 投影到切平面
   u = t·t1, v = t·t2                 // 切平面坐标
   // 方程：II11·u² + 2·II12·u·v + II22·v² = k_n
   ```
4. 最小二乘解 3 未知数 `[II11,II12,II22]`（法方程 `AᵀA x = Aᵀb`）
5. 主曲率 = `[[II11,II12],[II12,II22]]` 的特征值；H=(k1+k2)/2，K=k1·k2

#### 4.3 Rusinkiewicz —— 逐面法向变化张量

对每个面 `(P0,P1,P2)`，法向 `(n0,n1,n2)`（取自 `vn`）：
1. 建局部标架：`e1=normalize(P1-P0)`，`Nf=normalize((P1-P0)×(P2-P0))`，`e2=normalize(Nf×e1)`
2. 对三条边，把法向差投影到面平面：
   ```
   dn01=(n1-n0), dp01=(P1-P0)   → 投影 dn01 到 (e1,e2) 得 (du01,dv01)，dp01 投影得 (x01,y01)
   // 同理边 02、12
   ```
3. 形状算子 `S`（2×2 对称）满足 `dn = -S·dp`，三条边 6 方程最小二乘解 3 未知数
4. 该面 `S` 的特征值 = 面主曲率；记录到面
5. **逐顶点累积**：把每面的 `S`（旋转到统一朝向后）按 Voronoi 面积加权累加到 3 个顶点；顶点处 `S` 的特征值 = 顶点主曲率

> Rusinkiewicz 步骤 5 的旋转：每面 `S` 在各自局部 `(e1,e2)` 基下，累积到顶点前用顶点切平面基做 2×2 旋转 `S' = R S Rᵀ`。顶点累积 `S` 取特征值得 `(k1,k2)`。

#### 4.4 `compute_face_curvature`

对每个面，取其 3 顶点曲率按面内子三角形面积（或均匀 1/3）加权：
```
out[f].mean    = Σ wᵢ·vc[vi].mean
out[f].max_abs = max_i |vc[vi].principal_max|  // 取最陡
out[f].gaussian= Σ wᵢ·vc[vi].gaussian
```

#### 4.5 `layer_height_from_curvature`（弦误差模型）

```
k = curv.max_abs
return (k > 1e-6) ? sqrt(8*max_surface_deviation/k)   // 弦-弧偏差 ≤ dev
                  : FLT_MAX                            // 平面→不限
```
> 依据：曲率 k 的圆弧上长 L 的弦，弦弧偏差 ≈ k·L²/8；令其 ≤ dev 得 L ≤ √(8·dev/k)。

#### 5.2 曲率分节（文档要点）

```cpp
// ========================================================================
//  Mesh Curvature（网格离散曲率）
//
//  离散微分几何曲率（主曲率/平均曲率/Gauss 曲率）。与斜率互补：斜率只
//  描述面相对切片方向的倾角；曲率描述局部表面弯曲程度（尖锐棱、凹谷、
//  平坦区），可作为更精细的自适应层高判据（高曲率区用更薄层）。
//
//  三种估计方法：
//    • Meyer（默认）：Voronoi 面积加权离散 Laplace-Beltrami + 角度亏损，
//      精度高、对网格质量敏感；
//    • Taubin：切平面二阶基本形式最小二乘，稳健；
//    • Rusinkiewicz：逐面法向变化张量传播，保留方向信息。
//
//  【符号约定】外法向下，凸面（球体外侧）H>0、K>0；鞍点 H≈0、K<0。
//  【典型流程】1) mesh_vertex_curvature 得每顶点曲率；
//    2) mesh_face_curvature 聚合到面；3) mesh_layer_height_from_curvature
//    映射为层高；或在 next_cusp 流程中替代/补充斜率判据。
//  ========================================================================

/// @brief 计算每个顶点的离散曲率（主曲率/平均/Gauss）。
///
/// 对每顶点估计 k1,k2 并导出 H=(k1+k2)/2、K=k1·k2。凸面（外法向）H>0。
///
/// @param[in]  its    输入网格（建议封闭流形以获稳定结果）。
/// @param[out] out    每顶点曲率，长度==its.vertices.size()。
/// @param[in]  method 估计算法：Meyer(默认)/Taubin/Rusinkiewicz。
/// @return Ok / EmptyInput / GeometryFailure(退化解失败)。
static ErrorCode mesh_vertex_curvature(const indexed_triangle_set& its,
                                       std::vector<mesh::VertexCurvature>& out,
                                       mesh::CurvatureMethod method = mesh::CurvatureMethod::Meyer);

/// @brief 由顶点曲率面积加权聚合到每面曲率。
/// @param[in]  its         输入网格。
/// @param[in]  vertex_curv mesh_vertex_curvature 的输出。
/// @param[out] out         每面曲率，长度==its.indices.size()。
/// @param[in]  method      与顶点一致的算法（仅作记录用）。
/// @return Ok / EmptyInput / InvalidArgument(vertex_curv 长度≠顶点数)。
static ErrorCode mesh_face_curvature(const indexed_triangle_set& its,
                                     const std::vector<mesh::VertexCurvature>& vertex_curv,
                                     std::vector<mesh::FaceCurvature>& out,
                                     mesh::CurvatureMethod method = mesh::CurvatureMethod::Meyer);

/// @brief 由面曲率推导该面允许的最大层高（弦误差模型）。
///
/// 高曲率（尖锐弯曲）→ 薄层；平面（k≈0）→ FLT_MAX。公式 h=√(8·dev/k)，
/// 保证圆弧弦偏差不超过 dev。
///
/// @param[in]  curv                   目标面曲率。
/// @param[in]  max_surface_deviation  允许最大表面偏差（mm，>0）。
/// @param[out] out                    允许最大层高（mm）。
/// @return Ok / InvalidArgument(dev≤0)。
static ErrorCode mesh_layer_height_from_curvature(const mesh::FaceCurvature& curv,
                                                  float max_surface_deviation, float& out);
```

#### `tests/test_mesh_curvature.cpp`（**真实曲率验证**，8 用例）

用已知解析曲率的几何体验证（`make_sphere`/`make_cylinder`/`make_cube`）：

1. **`unitest_mesh_curvature_sphere_meyer`** — 球 R=10 (slices=48,stacks=24)：统计所有非极点顶点 H 均值 ≈ 0.1（容差 ±40%），K 均值 ≈ 0.01；principal_max/min 均 ≈ 0.1
2. **`unitest_mesh_curvature_sphere_taubin`** — 同上，Taubin 法 H 均值 ≈ 0.1（容差 ±50%）
3. **`unitest_mesh_curvature_sphere_rusinkiewicz`** — 同上，Rusinkiewicz 法 H 均值 ≈ 0.1（容差 ±50%）
4. **`unitest_mesh_curvature_plane`** — 平面（扁平 cube 或 make_cube 高度极小）：所有面顶点 H≈0、K≈0（< 1e-3）
5. **`unitest_mesh_curvature_cylinder`** — 圆柱 R=10：侧面顶点 k1≈0（轴向）、k2≈0.1（周向）；K≈0；H≈0.05
6. **`unitest_mesh_curvature_methods_consistent`** — 同一球，三种方法 H 均值彼此相差 < 2×（量级一致）
7. **`unitest_mesh_face_curvature_sphere`** — 球的面曲率 mean ≈ 0.1
8. **`unitest_mesh_layer_height_from_curvature`** — k=0.04(对应 R=25) + dev=0.1 → h=√(8·0.1/0.04)=√20≈4.47；k≈0 → FLT_MAX；dev≤0 → InvalidArgument；空网格 → EmptyInput

> 容差说明：离散曲率对网格质量/顶点价敏感（尤其球极点高价），故用"非极点顶点均值 + 较宽容差"而非逐顶点精确比对。
