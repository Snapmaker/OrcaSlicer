# EdgeSlicer 2.4.1.2

<!-- update-notice -->
2.4.1.2 adds Bambu reprint from the EdgeSlicer phone app and fixes a crash in the Network Test dialog.
New:
- Reprint a past Bambu job from the phone to any Bambu printer of the same model, with an AMS slot picker and the usual print options.
Fixes:
- Closing Help › Network Test while a test was still running could crash EdgeSlicer a few seconds later.
<!-- /update-notice -->

Everything in [2.4.1.1](https://github.com/aceRage/EdgeSlicer/releases/tag/v2.4.1.1-edge) is included.

## New

- **Bambu reprint from the phone.** The phone app's Reprint list now includes Bambu jobs. You can send one again to any Bambu printer of the same model.
  - Before sending, the hub asks the printer what is loaded and shows an **AMS slot** sheet. Each filament gets its proposed slot, with its colour. Two-nozzle printers (H2D/H2C) show the left/right side. You can pick another slot.
  - The print options can be changed: timelapse, bed leveling, flow calibration and nozzle offset calibration.
  - The job goes out through the same plug-in calls as a send from the desktop.
  - This needs the updated EdgeSlicer phone app.
- **Phone plate send on two-nozzle printers** now maps filaments to AMS slots per nozzle side, like the desktop send dialog. The desktop dialog, the phone plate send and the phone reprint now share one mapping.

## Fixes

- **Network Test crash.** Closing **Help › Network Test** while a test was still running (for example the LAN check against an offline printer) could crash EdgeSlicer a few seconds later. The tests now stop cleanly when the dialog closes, and closing it never freezes the window. The LAN connection check now gives up after 10 s instead of about 21 s.
- The application icon files are renamed from Snapmaker_Orca to EdgeSlicer. Nothing changes in how the icons look.
